## Application brand

`Assets/app-logo.png` and `Assets/wisp.ico` use an original generated Wisp spirit-orb design created for this project on 2026-10-27. They are separate from Valve's Io avatar. The ICO is a multi-resolution export of the app logo; no third-party game artwork is used in the application icon.
