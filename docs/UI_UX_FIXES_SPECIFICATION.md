# Wisp — исправления UI/UX (29.10.2026)

Источник: новое прямое ТЗ пользователя. Дополняет предыдущие требования; заменяет прежние размеры/пропорции только там, где явно указано. Существующие WPF/C#/.NET, Onest/Grayscale, SFU, база, голос/демонстрация/трей сохраняются. HTML/CSS/JS/WebView2 для UI не использовать.

1. Настройки пользователя/сервера: внешний отступ увеличить втрое от текущих16 до48 логических единиц, одинаково со всех сторон. Размеры учитывать минимум800×560, не выходить за окно. В шапке тонкая нижняя граница на всю ширину, тематический цвет. Устранить белое мигание открытия/закрытия/переключения: исследовать фон, инициализацию дерева, opacity/переходы, не добавлять искусственные задержки и не выдавать предположения за доказательства.
2. Rail: стабильная активная вертикальная полоска без исчезновения/мигания при hover/обновлении списка/переключении секций настроек. Не перезапускать конфликтующие анимации, сохранять элементы. Серверные аватары чуть меньше, больше зазор от полоски, квадрат со скруглёнными углами и общим радиусом, корректная обрезка изображения/GIF и фирменный fallback.
3. Профиль: баннер **400×140 логических px,20:7**, заменяет16:9 во view/edit/preview/crop/save. Без искажений, с DPI. Общая система внутренних отступов для текста/полей/баннера/аватара/кнопок/секций через общие ресурсы/стили. About: Top/Left, multiline, нормальный padding, корректный scroll длинного текста. Удалить управление статусом из редактора; систему статусов сохранить.
4. Вне голосового канала полностью Collapsed дополнительный блок действий (share/watch/soundboard/leave/прочее), без пустого места. Mic/deafen пользователя остаются доступны и работают. В voiceblock равномерные колонки, одинаковые промежутки/кликабельные области, симметричные внешние отступы, центрирование иконок.
5. Шестерёнка канала: внутри общей строки, hover названия→gear не скрывает её, собственный hover, нажатие только настройки, без подключения/переключения. Фон selected/hover общий под названием и gear без разрыва. Проверить IsMouseOver родителя, hit testing, события, Z-index/маршрутизацию. Без вложенных конфликтующих Button; две независимые интерактивные зоны. Текстовые gears также проверить.
6. Общий focus-visible: mouseclick не оставляет focus-outline, Tab/keyboard показывает индикатор. Deactivated очищает визуальный focus/pressed/hover/tooltips; Alt+Tab не возвращает старую mouseобводку. Keyboardfocus и навигацию сохранить, глобально Focusable=False не использовать. Проверить navigation/settings/contextmenu/modal/voicebuttons и Window Activated/Deactivated/Inputevents/ToolTip/ControlTemplate.
7. Настройки: Cursor=Hand на интерактивных вкладках/боковой навигации/переключателях секций, общий стиль, не над пассивными областями.
8. Home: **реальный ASCII-рисунок исходного графического логотипа**, не баннер букв WISP и не только лог. Изучить ресурс, вручную нарисовать узнаваемую форму, показать TextBlock с monospace/сохранением пробелов/адаптацией/фирменным цветом. Графические логотипы в остальных местах сохранить. Прежний startup-log можно оставить.
